# Claude Prompts

## Design Creation from Reference Screenshots
Please use this prompt for creating designs in Claude Design using the published GitHub Pages website and the reference images found in this project.
 
 ```
I have a personal website at a public URL.  I also have 22 design reference screenshots to use to try 22 different design versions of this website.  Can you help me do this?  What do you need?
```

```
Here is the URL:  https://mvanmarter.github.io/peace-champion/
Please use the attached folder for reference screenshots.  Can you please create different designs of the website found at the listed URL for each of these reference screenshots?  Do NOT use the Halfaversary design system, and only use the refenece screenshot images that DO NOT have the words "desktop" or "mobile" in the file name.

```
